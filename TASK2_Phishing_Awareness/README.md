# PhishGuard – Phishing Awareness Training Program

## CodSoft Cyber Security Internship – Task 2

### Project Overview
PhishGuard is an interactive, web-based phishing awareness training module designed to educate users about phishing attacks and online security threats.

It helps users understand how cybercriminals use deceptive emails, fake websites, and social engineering techniques to steal sensitive information.

### Objectives
- Understand different types of phishing attacks.
- Identify suspicious emails, fake login pages, and fraudulent websites.
- Learn about common social engineering techniques.
- Follow practical cybersecurity safety tips.
- Test knowledge through an interactive quiz.

### Features
- **Learning Section:** Introduction to phishing and how phishing attacks work.
- **Attack Types:** Information about email phishing, spear phishing, whaling, and other attacks.
- **Identify Phishing:** Learn to recognise suspicious messages and warning signs.
- **Social Engineering:** Understand techniques such as authority, urgency, and pretexting.
- **Real-Life Case Study:** Business Email Compromise case involving Evaldas Rimasauskas.
- **Protection Tips:** Learn safe online practices and what to do after clicking a suspicious link.
- **Interactive Quiz:** Test phishing awareness and knowledge.

### Technologies Used
- HTML5
- CSS3
- JavaScript

### User Interface
The website uses a modern dark-themed cybersecurity interface with:
- Navy and purple colour palette
- Cyan and magenta highlights
- Interactive learning cards
- Responsive layout

### How to Run the Project
1. Download or clone this repository.
2. Open the `TASK2_PHISHING_AWARENESS` folder.
3. Open `index.html` in a web browser.
4. Navigate through the learning sections and complete the quiz.

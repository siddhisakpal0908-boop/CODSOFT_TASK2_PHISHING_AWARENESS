# PhishGuard – Phishing Awareness Training Website

## About the Project
PhishGuard is an interactive phishing awareness training website developed as part of the CodSoft Cyber Security Internship (Task 2).

The project aims to educate users about phishing attacks, help them identify suspicious messages, and promote safe online practices.

## Features
- Introduction to phishing attacks
- Common types of phishing
- Examples of suspicious emails and messages
- Warning signs to identify phishing attempts
- Safety tips and prevention techniques
- Interactive awareness content

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the `TASK2_Phishing_Awareness` folder.
3. Open `index.html` in a web browser.
